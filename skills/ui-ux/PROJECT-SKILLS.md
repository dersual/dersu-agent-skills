# Project-level UI / UX Skills

This file lists project-scoped AI skills and resources for frontend design, UI, and UX work. Use these when you want skills or resources to be available for a specific repository or project (not globally installed). Keep this file in the repository so collaborators can find and install the same project-level tools.

> Note: This repository already documents global plugins and MCP servers in PLUGINS-AND-MCP.md (see the Hugging Face example). The entries below are intended for project-local usage and links; install/usage instructions vary by skill and are intentionally minimal here — include specific install steps in project README or scripts when you adopt a skill.

---

## How to use

- Add a project-local `skills/` or `.gemini/config/plugins/` folder in the repository and include the skill sources or a README describing how to add them to a developer environment for this project.
- Prefer linking to upstream repos and authoritative documentation rather than copying implementation into this repo.
- For prose/copy generated by AI, run the humanizer skill to remove AI writing patterns: `skills/humanizer` (see `skills/humanizer/SKILL.md`).

---

## UI / UX Project Skills & Resources

1) nextlevelbuilder / ui-ux-pro-max-skill

- Repo: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- npm / usage: follow the skill's README in the linked repo for install / usage details. Treat it as a project-scoped skill if you only want it available for this repo.
- Why include: focused AI-first UI/UX guidance, templates, accessibility checks, and design prompt helpers useful for frontend feature work and design systems.

---

2) Impeccable.style

- URL: https://impeccable.style/
- What it is: curated UI patterns, visual language, and accessible component guidance; great for inspiration and concrete pattern recommendations when designing interfaces.
- How to include in a project: link the site in your design docs, or mirror small reference excerpts into `design/` docs (with attribution) that the project's agent skills can reference.

---

3) Hugging Face Skills (example)

- Repo / link referenced in PLUGINS-AND-MCP.md: https://github.com/huggingface/skills
- Why include: model search, dataset exploration, and tooling for fine-tuning — useful for research or LLM-powered UI experiments. See PLUGINS-AND-MCP.md for a short install example.

---

## Suggested project layout

- .gemini/
  - config/
    - plugins/
      - ui-ux-pro-max-skill/   (clone or link to the skill for project-local availability)
- skills/
  - humanizer/                (existing skill in this repo; use for copy-editing AI-generated text)
- design/
  - README.md                 (include links to Impeccable.style and notes for contributors)
