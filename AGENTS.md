# AGENTS.md — dersu-agent-skills

Guidelines for maintaining the skills and templates in this repository.

- **Skill Structure**: Each skill must contain a valid `SKILL.md` with YAML frontmatter (`name`, `description`).
- **Technical English (ASD-STE100)**: Write short, direct sentences with one main action per sentence. Avoid conversational filler.
- **Autonomous Discovery**: Inspect files and test commands without asking permission.
- **Verification**: Verify markdown links and skill frontmatter before completing tasks.
- **Safety**: Obtain approval before executing git commits, pushes, or destructive actions.
